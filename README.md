# MovieBox

Movie app built with React Router v7, Tailwind CSS v4 and TypeScript. Data and posters come from [TMDB](https://www.themoviedb.org/).

## Setup

1. Get a free API Read Access Token: https://www.themoviedb.org/settings/api
2. Copy `.env.example` to `.env` and paste your token.
3. Run it:

```bash
npm install
npm run dev
```

Pages are URL-driven: `/?page=3`, `/?q=batman&page=2`.
